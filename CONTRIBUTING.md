# Contributing

Thanks for helping improve **James VS Celtics**.

## Data rules

- Every player card must include at least two source URLs.
- New or changed stats must be checked against reputable public sources such as NBA.com, Basketball-Reference, Hall of Fame pages, or established media rankings.
- Keep media commentary short and paraphrased. Do not copy article passages into the data files.
- Keep the snapshot date explicit when updating active-player data.

## Visual rules

- Do not add NBA, team, or player-owned logos.
- Do not commit unlicensed player photos.
- Prefer original abstract card art, silhouettes, court lines, and CSS/Canvas effects.

## Development

```bash
npm install
npm run dev
npm test
npm run build
```

Before opening a pull request, make sure tests and the production build pass.
